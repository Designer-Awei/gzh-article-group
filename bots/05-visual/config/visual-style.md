# 视觉规范（模板）

> 初始化（gzh-init 第 2 步）时由视觉官按用户的账号定位填写。未填写时使用下面的「中性默认」。

## IP 角色
- 见 [ip/ip-spec.md](ip/) （初始化时由 [ip/ip-spec.template.md](ip/ip-spec.template.md) 生成）。如设定了 IP，每次生图都必须把 ip-spec.md 中的标准参考图作为参考图传入，保持形象一致。
- 未设定 IP：不画吉祥物角色，配图以场景、物件、图表或示意为主。

## 画风
- 底色：<填写，默认纯白，不加纹理、渐变、阴影>
- 线条：<填写，默认干净的黑色线条>
- 强调色：<填写一个色值，默认 #F26B5B>，全图只用这一种强调色，点到为止
- 构图：一个一看就懂的场景讲清一个观点
- 文字：标题放左上；除标题和必要标签外不加其他文字，不放 logo

## 规格
- 默认由视觉官按内容和用途自行选择比例：16:9、4:3、1:1 或竖版（3:4、9:16）
- 只有用于微信公众号文章封面时，才用 2.35:1：先生成 16:9，主体放在竖向中间带，再裁成 2.35:1（如 1024x436）

- 只使用用户自己的原创 IP，不使用他人 IP 或受版权保护的角色
