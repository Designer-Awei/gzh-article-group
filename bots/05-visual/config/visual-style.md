## IP 角色：灰章鱼（标准参考图 ip/octo-anchor-v1.jpg，每次生图必须作为参考图传入）
- 浅灰色、蛋形圆润脑袋，铅笔排线质感的灰色填充
- 黑色豆豆眼，一条短平的小嘴，一本正经、面无表情的呆萌感
- 戴黑色耳机，头顶长一丛珊瑚色珊瑚（唯一的 IP 色彩标识）
- 八条短粗圆头触手，触手底部有小圆点吸盘
- 动作永远很认真，场景可以荒诞

## 画风（源自 C 方案 / visual-ip-illustrations 手绘角色风）
- 纯白底，不加纹理、渐变、阴影
- 粗糙黑色马克笔线条，手绘感
- 全图只用一种强调色：珊瑚色 #F26B5B 左右，点到为止
- 一个荒诞但一看就懂的场景讲清观点
- 中文标题手写体，放左上；除标题和必要标签外不加其他文字，不放 logo

## 规格
- 默认由视觉官按内容和用途自行选择比例：16:9、4:3、1:1 或竖版（3:4、9:16）
