## 按选题挑样式
1. 先看文章在干什么：盘点/实测/教程、截图多 → 02；深度解读/观点/特写、文字为主 → 03；事件经过/历程/流程 → 04；公司/人物故事、估值、强对比 → 01。
2. 再看话题情绪：事故、伦理、裁员等负面新闻 → 03（或 01），不用 02、04。
3. 金融估值类不用 04（票根、便签太俏皮）。
4. 截图主色和母版主色撞色（如大量蓝色界面配 02）时换一套。
5. 同一系列尽量固定一套。
6. 拿不准默认 01。

## 固定规则（2026-10-15 起，四套都适用）
- **素材截图不套外框**：截图和 GIF 直接放裁好的图（1px 浅灰细边 + 小圆角），不套窗口、拍立得、相框；窗口/卡片只用在正文组件（导语、金句、要点、对比、代码）。
- **引用用 [xx] 序号 + 文末引用表**：正文句尾 `[xx]` 渲染成上标，和前一个字粘在一起；文末「参考资料」表只有「编号 | 链接」两列，编号列 white-space:nowrap + 最小宽度 44px，链接以稿件为准。取代旧的「句尾链接、最多 5 个」。publish：[cite] 正文序号和引用表一一对应，[ref] 两列格式 + 编号列 nowrap + 390px 实测不换行，[link] 正文还有 Markdown 链接就标 ✗。引用表样式跟各套风格走（见各 README）。
- **成品不带标题，副标题单独交付为摘要**：成品里没有标题和副标题；副标题原文写进输出目录的 `summary.txt`，用户填到公众号「摘要」栏。publish 的 [head] 检查成品里不能出现这两句原文。
- **开头区每套不同**：只用标签、日期、阅读时长、章节数和一句话导语组合（见上表），后面紧跟第一张截图。layout-map 的 `date` 只填稿件或选题里写明的实际发布日期，没有就不写（自动省略）；`tag` 默认「<栏目名>」。
- **长链接只在符号处断行**：参考资料表的链接只在 / . - ? & = 后面换行（插 `<wbr>`，vass/gzh 通过），不用 word-break:break-all。
- **对比卡中间不加 VS**。

## SVG 与字体（三套共用的规则）
- 动画只用内联 SVG + SMIL（animate / animateTransform），不准 CSS 动画、JS；svg 里不准 id、class、href、defs、use。不对 width/height 做无限循环动画。动画要手机实测。
- 四套的 data 数字样式都带 white-space:nowrap（01 于 2026-10-15g 补上；vass、gzh 均通过），数字和单位不会被拆到两行；publish 的 `[nowrap]` 检查。
- 不写 font-family（[spec] 必须 0）。衬线感用字重、细线、字距模拟（见 03 README）。

- 新母版按下一个编号建目录，必须带 README.md（组件表、参考来源、调性、适用、不适用、用法）、preview/ 和 preview/components-*.png，并在本表加一行。

### card_fit 是什么
publish 末尾的末行检测（[orphan]）发现金句卡、导语卡、重点卡或小标题在 390px 下最后一行只剩 1–2 个字时，会自动试几组内边距/字号/字距，把能解决问题的那组写进 layout-map.json 的 `card_fit`，格式是 `{"键": {"box": "卡片外框追加样式", "text": "文字追加样式"}}`。键：卡片文字前 12 字；导语卡 `lead`；小标题 `h:` + 去掉「一、」后的标题前 12 字。
- 这是排版自动生成的，人一般不用手写；可以手动删掉某条让它重测。
- 它和样式绑定：换母版、或改了那句话，都要删掉对应条目重跑。
- 内联高亮（highlight/marker）不进 card_fit，调不动只报警，退回文案官。

### 其他 map 开关
- `"data_cjk": true`：数字前紧挨汉字（「其中七成」「降低90%」）时也放大。默认关（旧稿重排版面不变）。

## 固定规则：图注只占一行（[capline]，2026-10-13 18:00 起）
- 手机宽 390px 下，每张图（截图、GIF、配图、代码卡片）的说明只能占一行。超出一行就**精简文字**，不准缩小字号、不准改字距。
- 经验长度：约 22–24 个汉字；不带「来源：」前缀，只写画面内容。
- publish 打印 `[capline] 图注 N 条，超过一行 M 条` 并列出超行的说明。只报警，不自动改。
