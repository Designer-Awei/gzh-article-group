# 01-珊瑚默认 适用说明

（本目录的 README.md 是母版技术说明，与 master/README.md 同步；这份只讲「什么时候用」。）

## 整体调性
白底，珊瑚色 #F26B5B 是主角：大号珊瑚色章节序号「01 —」、珊瑚浅底高亮、带错位投影的导语卡、不对称圆角金句卡、虚线框签名卡。活泼、亲和、有手绘感，像一个人在讲故事。

## 适合的主题和文章类型
- 产品/公司/人物故事、融资估值、行业八卦向的解读（首发：Jev 估值）
- 有明确观点、需要「金句」托底的评论文
- 数据点不多但需要几个醒目数字的文章（data 高亮）
- 有正反两面对比的选题（两套都有对比卡；01 的是珊瑚色实底 + 灰底圆角两栏，对比更跳，适合当全文卖点）

## 不该用的情况
- 截图、GIF、代码块很多的实测/教程/盘点类长文：彩色序号和圆角卡片会和密集截图抢视线，用 02-window-terminal（正文组件装进窗口卡、终端代码块，截图直接放，整体更像工具文档）
- 严肃、负面、事故/伦理类话题：珊瑚色大块装饰显得轻佻
- 整篇需要冷静中立、偏报道口吻的稿子

## 用法
`python3 bots/06-layout/config/master/publish.py <输出目录> <稿件.md> [素材目录]`（master 默认就是 01）

## 固定规则：图注只占一行（[capline]，2026-10-13 18:00 起）
- 手机宽 390px 下，每张图（截图、GIF、配图、代码卡片）的说明只能占一行。超出一行就**精简文字**，不准缩小字号、不准改字距。
- 经验长度：约 22–24 个汉字（英文和数字窄一些，可以多放几个）；仍不带「来源：」前缀，只写画面内容。
- publish.py 会用 orphan.js 逐条测量，打印 `[capline] 图注 N 条，超过一行 M 条`，并列出每条超行的说明和行数。只报警，不自动改；请改 layout-map.json 里的 cap。
