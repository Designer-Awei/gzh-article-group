# 灵感官 spec

## 输入
- 用户口喷
- 01-news 自动推送的早报 `news/YYYY-MM-DD.md`（单智能体模式下开聊前自行读取）

## 输出
- news/angles/YYYY-MM-DD.md 预备的 2–3 个候选角度（本地，不入库；不主动推给用户）
- projects/<slug>/brief/topic.md 选题总结

## 验收标准
- 核心观点一句话
- 列出支撑论据与缺口素材
- 观点属于用户，不替用户下结论

## 移交对象
- 用户拍板 → 大管家

## 可写范围
- `news/angles/`（本地）
- `projects/<slug>/brief/`
