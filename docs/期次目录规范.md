# 【新洞察】单期目录规范（不新建仓管 bot）

原则：**排期官管顺序与状态；每期一个项目文件夹管全部产出。** 大管家开项目时按此脚手架创建。

## 推荐路径

```
projects/YYYY-MM-DD-<slug>/
  README.md                 # 期次、标题、状态、排期序号
  brief/
    topic.md                # 灵感/拍板摘要
    topic-scorecard.md      # 主编选题评分卡（可选）
    research-brief.md       # 主编研究简报（下游唯一解释源）
  source/                   # 或与 materials/ 互链
    materials.md
    shots/
  draft/
    正文.md / 用户润色.txt
  illustration/             # 视觉官配图（也可链 visual/out/）
  cover/                    # 封面（用户自制）
  layout/
    preview-standalone.html # 交付物
  review/
    验收报告.md
    editor-redteam.md       # 主编反向审稿
  handoff.json              # 可选流水线日志
```

## 全局索引（已有，不另建仓管）

| 用途 | 路径 | 谁维护 |
|---|---|---|
| 排期台账 | `config/editorial-calendar.md` | 排期官 |
| 中长期选题方案 | `plans/` | 排期官登记链接；内容可来自用户/灵感/主编 |
| 早报 | `news/` | 资讯官 |
| 口喷与选题卡 | `ideas/` | 灵感官 |
| 素材包（现行） | `materials/YYYY-MM-DD-主题/` | 素材官 |
| 定稿（现行） | `drafts/` | 文案官 |
| 配图（现行） | `visual/out/` | 视觉官 |
| 排版成品（现行） | `layout/out/` | 排版官 |

过渡期允许 `materials/`、`drafts/`、`visual/out/`、`layout/out/` 与 `projects/<slug>/` 并存；**新期优先全部落入 projects/**，排期表里写清路径。

## 不新建「仓管 bot」的原因

文件归属已按角色写死；再加仓管会多一层交接、容易和排期官/大管家职责重叠。若目录仍散，优先让大管家开项目时强制脚手架 + 排期官表里挂链接即可。
